# demo-sale

Три варианта демонстрационного сайта доставки еды в одном репозитории.

| Путь | Исходная версия | Локальный источник |
| --- | --- | --- |
| `/one` | sushistoroll-store.onrender.com | sushi_project_claude |
| `/two` | sushistoroll-hello.onrender.com | sushi_project_deepseek |
| `/three` | sushistoroll.onrender.com | sushi_project_best_1 |

Перенесены локальные исходники, наиболее близкие к опубликованным версиям.
Это не выгрузка исходников с Render: локальные версии могут содержать более поздние изменения.

## Локальная работа

Нужны Node.js 22+ и npm.

```sh
npm ci
npm run build
npm run preview
```

Общая сборка находится в `dist/`, preview доступен на http://127.0.0.1:4173.
Для разработки одного приложения: `npm run dev:one`, `npm run dev:two`, `npm run dev:three`.
Открывайте приложение с его префиксом, например http://localhost:5173/one/.

## Размещение на Render

В репозитории подготовлен `render.yaml` для одного бесплатного Static Site:

- Build Command: `npm ci && npm run build`
- Publish Directory: `dist`
- Root Directory: корень репозитория

Создайте Blueprint из репозитория либо настройте Static Site вручную и перенесите правила Rewrite и Redirect из `render.yaml`. Правила Redirect сохраняют переход со старых адресов.
Они направляют каждый префикс и вложенные страницы на HTML соответствующего приложения.
Существующие JS/CSS/шрифты Render отдаёт напрямую, до применения rewrite-правил.
См. https://render.com/docs/redirects-rewrites.

Желаемый адрес — `https://demo.onrender.com`, но имя сервиса само по себе не гарантирует этот поддомен: итоговый URL определяется Render и доступностью имени.
При другом домене пути приложений остаются прежними. Публикация и настройка аккаунта Render этим переносом не выполняются.

Проверьте после деплоя прямое открытие и обновление `/one/cart`, `/two/about`, `/three/checkout`, `/one/courier`.

## Границы текущего этапа

Кабинет доступен по пути `/account` внутри каждого варианта. Вход, профиль,
баланс и история заказов общие для трёх вариантов на одном адресе в одном браузере.
Корзина сохраняется отдельно для каждого варианта.

Для показа войдите в демоаккаунт, добавьте две «Филадельфии классик», примените
`SUSHI10` в корзине и выберите списание бонусов при оформлении. Сумма к оплате
с доставкой составит 729 ₽. Сначала имитируйте отказ, затем повторите и выберите
успех. В истории появится один заказ, а баланс изменится с 1000 до 800 бонусов.
Заказ можно открыть в кабинете любого из трёх вариантов.
В 00:00 по Москве корзины и история заказов очищаются, а баланс возвращается к 1000. Профиль и вход сохраняются. Если сайт закрыт, новый день применяется при следующем открытии. Кнопка «Сбросить профиль и историю» позволяет очистить данные аккаунта вручную.

Расчёты проверяются командой `npm test`.
Изображения Unsplash и Google Fonts загружаются из внешних источников.

При переносе настроены Vite base и BrowserRouter basename, исправлены ссылки логотипов и регистр имени локального шрифта для Linux-хостинга.
Исходные папки проектов не менялись.
